# Tick 因子汇总表

> 目的：根据本文档可使用 SH/SZ 原始逐笔表精准复现每个因子。
> **SH 表**：委托 `zz_39_1`、成交 `zz_39_2`、撤单 `zz_39_3`
> **SZ 表**：委托 `zz_05`、成交 `zz_06_1`、撤单 `zz_06_2`
>
> **基础量口径**（全表统一，下文不再重复）：
> - 成交额：SH 取 `zz_39_2.成交金额`；SZ 取 `zz_06_1.委托价格 × zz_06_1.委托数量`
> - 成交量：SH `zz_39_2.数量`；SZ `zz_06_1.委托数量`
> - 成交价：SH `zz_39_2.价格`；SZ `zz_06_1.委托价格`
> - 委托额：SH `zz_39_1.数量 × zz_39_1.价格`；SZ `zz_05.委托数量 × zz_05.委托价格`
> - 委托量：SH `zz_39_1.数量`；SZ `zz_05.委托数量`
> - 委托价：SH `zz_39_1.价格`；SZ `zz_05.委托价格`
> - 撤单额：SH `zz_39_3.价格 × zz_39_3.数量`（`成交金额` 恒 0 不用）；SZ 按 `(zz_06_2.频道代码, zz_06_2.消息记录号)` 关联到 `zz_05.委托价格`，再 `× zz_06_2.委托数量`
> - 撤销量：SH `zz_39_3.数量`；SZ `zz_06_2.委托数量`
> - 主动买/卖：SH 取 `zz_39_2.标识`（`B`=主动买、`S`=主动卖、`N`=集合竞价不计主动）；SZ 比较 `zz_06_1.买方委托索引` 与 `zz_06_1.卖方委托索引`，`买方委托索引 > 卖方委托索引` → 主动买，否则主动卖
> - 买卖方向：SH 委托/撤单按 `标识`（`B`/`S`）；SZ 委托按 `zz_05.买卖方向`（`49`=买、`50`=卖），撤单按非零的委托索引侧（`zz_06_2.买方委托索引≠0` → 买撤）
> - 关联键：SH 同侧 `zz_39_1.买方订单号`/`卖方订单号`；SZ `(zz_05.频道代码, zz_05.消息记录号)`
> - 时间戳：`HH:MM:SS.mmm` → 当日相对毫秒 `ts`
> - 大单阈值：对应金额序列（委托额/成交额/撤单额分别取）的 90 分位数
> - 小额阈值：成交金额序列的 10 分位数
> - 分钟桶：`bucket = ts // 60000`，桶收益 `(桶末笔成交价 - 桶首笔成交价) / 桶首笔成交价`
> - 未来价 `price(t+Δ)`：成交表中 `ts ≤ t+Δ` 的最后一笔成交价（`searchsorted(side='right')-1`）
> - `ref_price`（委托/撤单时点的参考价）：该时点前最近一笔成交价
> - 缺失处理：分母为 0 或样本不足时记 `NaN`，不填 0
