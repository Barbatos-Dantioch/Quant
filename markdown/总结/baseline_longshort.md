
# baseline_longshort 实验系列总结

> 输出目录：`output/baseline_longshort/`（仅有运行日志，无独立子实验目录）
> 主题：多空回测基线实验，作为后续 0407/0408/0409 等系列的对照基准

## 实验设计

- **数据**：`Data/short/panel.pkl`，2020-01-02~2026-02-11，3491 只股票，1088 特征，13 个半年区间
- **模型**：单模型 XGBoost 回归（沿用 `baseline_config.md` 中的标准配置），复用已训练的 `factor_df` 缓存
- **分组回测**：10 分组，头组为因子值最高的第10组
- **多空组合**：头组做多、尾组做空，未找到 `avg_return_daily.pkl` 时基准使用全市场等权日收益

## 回测结果

| 指标 | 数值 |
|---|---|
| Rank IC 均值 | 0.0659 |
| Rank IC IR | 0.4515 |
| 头组年化收益 | 9.93% |
| 尾组年化收益 | -28.13% |
| 多空年化收益 | 41.78% |
| 多空夏普比率 | 2.046 |
| 多空最大回撤 | -22.75% |
| 多空Calmar | 1.84 |
| 头组超额年化 | 3.01% |

## 说明

该系列仅作为基线对照，未做任何参数调优，是 0407_longshort、0408_factor_selection 等后续系列 fusion 模型改进的性能起点参考（注意：本基线为纯回归单模型，未使用 fusion 三模型融合，故多空表现明显弱于后续 fusion 系列的 BL-01 等基准，约 70% 年化）。
