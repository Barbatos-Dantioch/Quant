## 一、核心项目：OU-P-CRD30 配对多空策略

### 1.1 项目定位

A 股非 ST 全市场、**申万一级行业内**的股票配对（Pair Trading）多空策略。对每对股票构造 log 价差，用 **Ornstein-Uhlenbeck（OU）过程**建模均值回复；在 OU 估计前用 **SSD 路径相似度**筛 pair；经 OU 硬过滤、5 折交叉验证去重后，按 z-score 信号强度选股，**5 日轮换**等权多空。

回测区间 2024-01-01 ~ 2025-12-31，手续费 0.07%（双边）。多空年化 **34.2%**，夏普 **1.52**，最大回撤 **−14.0%**，Calmar **2.44**。

### 1.2 策略参数一览

| 模块 | 设定 |
|------|------|
| 标的池 | A 股非 ST |
| 配对范围 | 申万一级行业内两两枚举（i < j） |
| 价差 | X_t = ln(P_i,t) − ln(P_j,t) |
| 训练窗 | 252 个交易日 |
| 验证窗 | 20 个交易日 |
| 相似度预筛 | SSD 路径相似度，行业内保留 top 30% |
| OU 估计 | 训练窗 AR(1) OLS → κ, μ, σ, half_life |
| 平稳性 | ADF 检验，p < 0.05 |
| OU 硬过滤 | b ∈ (0,1)，half_life ∈ [5, 30] 天 |
| 配对质量 | 训练窗 5 折 CV → cv_mean_ic |
| 去重 | 行业内贪心，每只股票最多 1 对，按 cv_mean_ic 降序 |
| 空头池 | 市值前 50% ∩ 波动率前 40% ∩ 可交易 |
| 信号 | z-score：κ · (μ − X_t) / σ |
| 选股 | 合法 pair 中按 \|signal\| 取 top 20%，至少 50 对 |
| 持仓 | 5 日轮换，等权多空 |
| 成本 | 手续费 0.07%（双边） |

### 1.3 全流程（每个截面日 t）

#### Step 1：数据准备与窗口切分

- 输入：全市场 log 收盘价宽表、日收益、申万行业、市值、可交易状态
- 训练段：[t − 272, t − 21)，共 252 日，用于 SSD 预筛与 OU 估计
- 验证段：[t − 21, t)，共 20 日，用于 valid_rank_ic（诊断）及 CV 标签对齐
- 信号日：t，取当日 X_t = ln(P_i,t) − ln(P_j,t) 计算交易信号
- 剔除训练/验证/信号日任一段有缺失的股票

#### Step 2：行业内枚举 pair

- 按申万一级行业分组
- 组内满足数据完整的股票，做 $C_n^2$ 两两配对
- 每对构造 252 日价差矩阵 X_train，形状 (252, n_pair)

#### Step 3：SSD 路径相似度预筛

对每对 (i, j)，在 252 日训练窗内：

$$X_t = \ln P_{i,t} - \ln P_{j,t}, \quad X'_t = X_t - X_0$$

$$\text{SSD} = \sum_{t=1}^{252} (X'_t)^2, \quad \text{pair\_score} = -\text{SSD}$$

- SSD 越小 → 252 日内 spread 路径越平、两腿 log 价格越「同轨」
- 行业内按 pair_score 降序，**保留 top 30%**（向上取整，至少 1 对）
- NaN 置 −∞，不参与入选

#### Step 4：OU 参数估计

对预筛后的每对，252 日 X_t 做 AR(1) OLS 回归：

$$X_{t+1} = a + b \cdot X_t + \varepsilon_t$$

由 AR(1) 系数反推 OU 参数：

| 参数 | 公式 | 含义 |
|------|------|------|
| b | Cov(X_t, X_{t+1}) / Var(X_t) | 均值回复速度（b = e^{−κ}） |
| κ | −ln(b) | 回复速率 |
| μ | a / (1−b) | 长期均衡价差 |
| σ | √(res_var · 2κ / (1−b²)) | 稳态波动率 |
| half_life | ln(2) / κ | 偏离减半所需天数 |

仅 b ∈ (0, 1) 时 OU 参数有效；否则置 NaN。

#### Step 5：ADF 平稳性检验

并行对每对 spread 做 ADF 检验（带常数项 + 1 阶滞后差分）：

$$\Delta s_\tau = c + \rho \cdot s_{\tau-1} + \gamma \cdot \Delta s_{\tau-1} + \eta_\tau$$

取 p 值，要求 ADF_p < 0.05。

#### Step 6：OU 硬过滤

同时满足：

- b > 0（均值回复方向正确）
- 5 ≤ half_life ≤ 30 天（回复速度可交易）
- ADF_p < 0.05（价差平稳）
- μ、σ 非 NaN

#### Step 7：5 折交叉验证（CV5）

在 252 日训练窗内做 5 折 CV：

- 每折：4/5 数据估 OU → 1/5 验证段算 signal 与 label 的 Spearman IC
- label：未来 5 日价差变化（与 5 日持仓对齐）
- 5 折 IC 均值 → **cv_mean_ic**，衡量 pair 预测稳定性

#### Step 8：行业内贪心去重

- 按 cv_mean_ic 降序排列行业内所有通过过滤的 pair
- 贪心选取：**每只股票最多保留 1 对**
- 优先保留 cv_mean_ic 高、且不与其他已选 pair 争用同一股票的配对

#### Step 9：空头池约束

- 空头池定义：当日市值排名前 50% ∩ 波动率排名前 40% ∩ 可交易（非涨跌停/非停牌）
- 合法 pair：预测空头方（signal < 0 时做空的那条腿）必须落在空头池内

#### Step 10：信号计算与选股

信号日 z-score：

$$\text{signal}_t = \kappa \cdot \frac{\mu - X_t}{\sigma}$$

- signal > 0：X_t 低于均衡 μ，预期价差回升 → 做多 i、做空 j
- signal < 0：X_t 高于均衡 → 做多 j、做空 i

在全市场合法 pair 中，按 |signal_t| 降序取 **top 20%**，至少 50 对。

#### Step 11：组合构建与换仓

- 多头腿、空头腿分别等权
- **5 日轮换**：每 5 个交易日根据最新截面信号重新调仓
- 手续费 0.07%（双边），过滤涨跌停/停牌

### 1.4 回测结果

区间 2024-01-01 ~ 2025-12-31：

| 指标 | 数值 |
|------|------|
| 年化收益 | 34.2% |
| 年化夏普 | 1.52 |
| 最大回撤 | −14.0% |
| Calmar | 2.44 |

同类相似度预筛对照（同框架、仅预筛方法不同）：

| 预筛方法 | 保留比例 | 年化 | 夏普 |
|----------|----------|------|------|
| Pearson | 30% | 26.6% | 1.19 |
| Spearman | 30% | 29.7% | 1.37 |

### 1.5 核心 Insight

- SSD 直接度量 spread **路径形状**，比日收益相关更匹配 OU 对价差的建模对象
- 相似度预筛放在 OU **之前**，先缩小 pair 空间再估参数，减少弱 pair 噪声
- CV5 + 每股 1 对去重，保证入选 pair 在训练窗内预测稳定、且不重复占用同一股票
- half_life ∈ [5, 30] 与 5 日持仓周期匹配，是策略有效的重要约束
- **配对质量决定策略上限**，信号公式微调不如 pair 筛选关键

### 1.6 30 秒口述

> 配对策略的标的是A股多空股票。每个截面日，在行业内枚举 pair，先对配对股票的相似度，配对平稳性和回归周期的长度和稳定性、价差波动的来源进行筛选，用对预筛 pair 做 AR(1) 估计 OU 参数。训练窗 5 折 CV 算 cv_mean_ic，按照ic做贪心去重，让每股最多只能出现在一个配对中。预测信号是配对偏离均值的标准差乘配对的回归速度，合法 pair 按信号强度取 top 20%，5 日轮换等权多空。2024–2025 回测年化 34.2%、夏普 1.52。核心经验是先保证配对质量，OU 均值回复假设才成立。

## 二、SSD 路径相似度（详解）

### 2.1 计算步骤

1. 取 252 日训练窗价差：$X_t = \ln P_{i,t} - \ln P_{j,t}$
2. 起点归零：$X'_t = X_t - X_0$
3. 求平方偏差之和：$\text{SSD} = \sum_{t=1}^{252} (X'_t)^2$
4. 取负得 score：$\text{pair\_score} = -\text{SSD}$
5. 行业内按 score 降序，保留 top 30%

### 2.2 三种相似度度量对比

| 方法 | 输入数据 | 度量含义 |
|------|----------|----------|
| Pearson | 日 log 收益 | 涨跌同步性 |
| Spearman | 日收益秩 | 单调同步性 |
| **SSD** | **252 日 log 价差路径** | **两腿是否长期同轨** |

## 三、OU 参数估计（详解）

### 3.1 连续模型与离散化

连续 OU：$dX_t = \kappa(\mu - X_t)\,dt + \sigma\,dW_t$

日频离散 AR(1)：$X_{t+1} = a + b X_t + \varepsilon$，$b = e^{-\kappa}$

### 3.2 OLS 批量估计

对 (252, n_pair) 价差矩阵矩阵化做 OLS，一次估计所有 pair 的 b, a, κ, μ, σ, half_life。仅 b ∈ (0, 1) 时参数有效。

### 3.3 信号含义

$$\text{signal} = \kappa \cdot \frac{\mu - X_t}{\sigma}$$

κ 放大回复力度，σ 标准化偏离幅度。X_t 远低于 μ 时 signal 为正，预期价差向 μ 回归。

## 四、LGB 配对打分策略（0506 系列最优）

### 4.1 项目定位

在 OU 配对框架上，用 **LightGBM 对 pair 打分**替代纯规则 signal 排序，22 维 pair 级特征输入，2 种子集成 + 截面权重加权（WS）。

回测区间 2024-01-01 ~ 2026-05-13，多空年化 **36.7%**，夏普 **1.75**，最大回撤 **−11.4%**，Calmar **3.21**。

### 4.2 完整流程

1. **配对与预筛**：申万行业内枚举 → OU 硬过滤 → CV5 去重（同 OU-P-CRD30 框架）
2. **特征构造**（22 维 pair 级）：

   μ, κ, σ, half_life, b, ADF_p, mean_X, std_X, valid_rank_ic, cv_mean_ic, signal, X_t, abs_dev, sigma_20, sigma_30, z_OU, sigma_20_quantile, X_t_quantile, NZC_60, ret_i_20, ret_j_20, corr_ij_60

   **剔除市场与行业因子特征**，避免 beta 污染。

3. **模型训练**：LightGBM（max_depth=5, num_leaves=31, lr=0.05, feature/bagging_fraction=0.8, min_child=20, reg_lambda=1.0），2 随机种子集成
4. **标签**：未来 5 日 pair 相对收益
5. **选股**：模型打分替代 |signal| 排序，top 20% / 至少 50 对
6. **持仓**：5 日轮换，WS 截面权重加权，手续费 0.07%

## 五、0416 截面配对因子（多头）

### 5.1 项目定位

为每只股票 s 寻找「领先股」j，用 j 的信息构造 s 的截面选股因子，头组多头回测。

### 5.2 有效路径：协整 + holdout 验证（CO-18）

1. 申万一级行业内，log 价格协整检验（Engle-Granger + ADF）
2. **holdout 样本外验证**：训练 60 天 + 验证 20 天，筛稳定 pair
3. 因子：leader 价格 predict × 回归速率 (1−ρ*)
4. 结果：RankIC 0.041，头组年化超额 10.3%，IR 1.44

### 5.3 失败路径

- 相关性法（BL）、Granger 因果（GL）：头组普遍无效或负收益
- 无 holdout 的简单同业协整：RankIC 有效但头组超额为负（样本内过拟合）

## 六、因子相似度检验

### 6.1 方法

1. **截面 Spearman 相关**：每日全市场算因子 Spearman，时间取均值；|ρ| > 0.9 剔除弱 IC 因子
2. **IC 序列相关**：两条 Rank IC 时间序列的相关
3. **头组 Jaccard**：头组股票集合重叠度
4. **层次聚类 + 贪心去重**：按 |Rank IC| 降序，max corr 超阈值则剔除

### 6.2 阈值

| 场景 | \|ρ\| 阈值 |
|------|-----------|
| 去冗余 | > 0.90 ~ 0.95 |
| 显著共线性 | > 0.60 ~ 0.70 |
| 理想因子库 | < 0.50 |

## 八、常见追问速答

| 追问 | 简答 |
|------|------|
| SSD 是什么？ | 252 日 log 价差起点归零后，平方偏差之和；越小说明两腿越同轨 |
| SSD 和 Pearson 区别？ | Pearson 看日收益同步；SSD 看 spread 路径形状，更贴 OU |
| 为什么 top 30%？ | 实验显示 SSD 在 30% 时 Sharpe 1.52，50% 时仅 0.96 |
| CV5 做什么？ | 训练窗 5 折 CV，cv_mean_ic 衡量 pair 预测稳定性，去重排序键 |
| OU 为何用 AR(1)？ | OLS 可矩阵化批量估计数万 pair，计算快 |
| 5 日持仓为何有效？ | OU 半衰期过滤 5~30 天，持仓与回复速度匹配 |
| 空头池怎么定？ | 市值前 50% ∩ 波动率前 40% ∩ 可交易 |
| IC 有效为何头组仍亏？ | 样本内过拟合；需 holdout 验证配对稳定性 |

当前配对交易的问题
1.传统配对交易是对一个配对组合进行交易，同时做多和做空，但如果每个组合的多空不是1比1，多个配对组合之间的比例很难协调。如果按照1：1进行交易，当两只股票收益率比例不是1：1时，就会出现敞口
2.为什么要用模型对配对进行预测：单一的ou信号是线性的，模型可以学到配对不对称的非线性变化，也引入了多个资产的多个信号
可能的改进方向
1.将1v1改为1vn或nvn。
#1vn：两只资产之间的关系复杂，同向影响（比如所在同一行业/概念，受相同因素影响，或者是产业链上下游）和反向影响（比如两企业存在竞争关系，当一个企业强势时，另一个企业股价下跌）可能同时存在。另外，股票在不同行情的可以加入copula，刻画不对称相关，每个股票可以和多个资产配对（比如上涨期的配对的股票和下行期股票的配对不同，这样的效果类似lead-lag，比如与概念etf配对）。
#nvn：可以用聚类方法，比如同一个ETF，同一个概念等，将股票聚类，对类进行配对，降低个股噪音
2.恢复速度不对称，当价差高于均值时的恢复速度与低于均值时的恢复速度不同

配对交易关键在于如何判断配对关系是否破裂，形成合理的先验


如何用于高频：高频量化的信号噪音比低频更大，可以先过滤波动幅度低的区间，只保留多空方向明确区间，用信号明确的区间做匹配

日频聚合因子：幌骗，用盘口撤单进行识别，投资者使用盘口挂单进行定价。如果因为盘口虚假挂单，做出了错误定价，说明有泡沫。三个因素：短周期盘口订单，用decay+时间阈值做加权。统计盘口合法订单存活期内主动成交量。用总成交量做归一化。希望加入日内价格波动适中，散户占比，预计能提升效果。
